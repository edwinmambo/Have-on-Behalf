# 📦 Have On Behalf Assets & Early Tester Releases

This directory houses releases, distribution assets, and testing artifacts for the **Have On Behalf Liturgical Platform**.

## Contents:

- `releases/TESTER_GUIDE.md`: Comprehensive walkthrough for early-stage testers (testing cross-references, pitch pipe, hymns, and worship service liturgy).
- `releases/manifest.json`: Release manifest describing builds, architecture targets, and feature specifications.
- `releases/build-companion.sh`: One-step build script to compile the Flutter companion app.
- `.github/workflows/flutter-release.yml`: Automatic cloud build workflow that runs on GitHub Actions to compile the APK whenever you push to GitHub.
